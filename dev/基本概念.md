# 基本概念

## Perk

**Perk** 是一种可以被应用在枪械／配件上的词缀系统，每个枪械／配件可以拥有复数个 Perk。

Perk在游戏中作为枪械的NBT属性进行存储，对于Destination的枪械类型，都拥有一个 Perks 列表，结构见下：
```json
{
  "Perks" = [
    {
      "PerkId": "tacz_destination:reconstruction",
      "Upgraded": false
    },
    {
      "PerkId": "tacz_destination:hip_fire_grip",
      "Upgraded": true
    }
  ]
}
```
当枪械拥有对应类型的Perk时，它就能够执行特定Perk注册的逻辑。

Perk的标签数据由PerkId和Upgraded组成，前者是每个Perk的不重复ID，后者是Perk的升级状态，被升级的Perk拥有更好的效果或者数值（实际上是不同的Perk）。
